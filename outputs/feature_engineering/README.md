# Causal Variable Selection — Output Files

This directory contains outputs generated during the preliminary data validation and feature engineering stage of the Dynamic Pricing with Double Machine Learning project.

## Files

| File | Description |
|---|---|
| `transaction_validation_report.json` | Summary of transaction data validation checks |
| `transactions_preliminary_features.csv` | Transaction data with preliminary engineered features; stored in Kaggle |
| `promotion_features.csv` | Aggregated promotion features at the product-store-week level; stored in Kaggle |

## Data Access

The two large CSV files are stored separately in Kaggle because they exceed GitHub's individual file upload limit. Use the shared Kaggle notebook or dataset to access them.
