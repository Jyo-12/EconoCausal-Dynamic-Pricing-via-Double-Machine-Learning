\# EconoCausal — Day 2 Model Training



\## 1. Overview



Day 2 focuses on estimating the causal effects of mailer promotions on retail sales using \*\*Double Machine Learning (DML)\*\* and `CausalForestDML` from EconML.



This work extends the initial display-promotion analysis by examining mailer exposure at the product-store-week level using the Dunnhumby retail dataset.



\## 2. Objectives



\- Train a causal machine learning model to estimate the Individual Treatment Effect (ITE) of mailer promotions.

\- Use Random Forest models as nuisance estimators within the DML framework.

\- Analyze variation in estimated treatment effects across product-store-week observations.

\- Generate summary statistics and a visualization of the estimated effects.

\- Save model outputs for further analysis and comparison.



\## 3. Dataset



\*\*Source:\*\* Dunnhumby — The Complete Journey



The analysis uses transaction and promotion data aggregated at the product-store-week level.



\### Input data



| Dataset | Rows | Columns |

|---|---:|---:|

| Transactions | 2,595,732 | 12 |

| Promotions | 36,786,524 | 5 |

| Aggregated promotions | 483,320 | 5 |



\### Key variables



| Variable | Description |

|---|---|

| `PRODUCT\_ID` | Product identifier |

| `STORE\_ID` | Store identifier |

| `WEEK\_NO` | Week identifier |

| `SALES\_VALUE` | Sales revenue outcome |

| `mailer\_exposed` | Binary indicator of mailer exposure |

| `display\_exposed` | Binary indicator of display exposure |



\## 4. Data Preprocessing



The promotion data was prepared using the following steps:



1\. Standardized the product, store, and week join-key data types.

2\. Normalized the `display` and `mailer` category values.

3\. Created binary exposure indicators:

&#x20;  - `1` indicates at least one nonzero promotion category.

&#x20;  - `0` indicates no recorded exposure under the selected coding rule.

4\. Aggregated promotion records by `PRODUCT\_ID`, `STORE\_ID`, and `WEEK\_NO`.

5\. Retained one record per product-store-week combination to prevent duplicate-key expansion during merging.



The aggregated promotion dataset contained \*\*483,320 records\*\*, with zero duplicate keys.



\## 5. Model Training



\### Algorithm



\*\*Causal Forest Double Machine Learning (`CausalForestDML`)\*\*



The model estimates heterogeneous treatment effects using machine learning to account for observed covariates.



\### Model configuration



| Parameter | Configuration |

|---|---|

| Framework | EconML |

| Estimator | `CausalForestDML` |

| Treatment | `mailer\_exposed` |

| Outcome | `SALES\_VALUE` |

| Nuisance outcome model | `RandomForestRegressor` |

| Nuisance treatment model | `RandomForestClassifier` |

| Nuisance estimators | 100 trees each |

| Causal forest estimators | 200 trees |

| Training sample | 100,000 observations |

| Random state | 42 |



The model was trained on a reproducible random sample of 100,000 observations from the aggregated dataset.



\### Treatment distribution



| Treatment | Observations in full aggregated data |

|---|---:|

| No mailer exposure (0) | 133,132 |

| Mailer exposure (1) | 350,188 |

| \*\*Total\*\* | \*\*483,320\*\* |



\## 6. Results



The model generated 100,000 estimated treatment effects.



| Statistic | Estimated ITE |

|---|---:|

| Count | 100,000 |

| Mean | -0.072170 |

| Standard deviation | 0.365495 |

| Minimum | -4.234475 |

| 25th percentile | -0.276312 |

| Median | -0.064240 |

| 75th percentile | 0.141629 |

| Maximum | 4.461781 |



\### Interpretation



\- The mean estimated treatment effect was slightly negative.

\- The median estimate was also slightly negative.

\- The distribution contained both positive and negative estimated effects, suggesting heterogeneity across observations.

\- The estimated effects require further validation before drawing conclusions about the causal impact of mailer promotions.



\*\*Important:\*\* These are model estimates, not proof that mailer promotions cause sales to increase or decrease. Their validity depends on treatment assignment, confounding control, feature selection, and other causal assumptions. The units of the estimates follow the scale of the `SALES\_VALUE` outcome.



\## 7. Visualization



The estimated ITE distribution was plotted using Matplotlib.



The histogram helps visualize:

\- The concentration of estimates around zero.

\- The balance between positive and negative estimates.

\- Potential extreme estimated effects that may require further investigation.
